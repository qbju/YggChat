ダウンロード

最新版はv0.19.1。ファイルはGitHub Releasesから配信しています。

🤖

Android（APK）

おすすめ。QR読み取り、VPNモード、LANチャット、プロフィールサイトなど全機能。Android 7.0以降・arm64。

yggchat.apk
🪟

Windows

ダブルクリックでアプリのウィンドウ（WebView2）が開きます。WebView2がない環境では既定のブラウザで開きます。

windows-amd64.exe
🐧

Linux

chmod +x して ./yggchat-linux-amd64。-cli で端末チャットも。

linux-amd64
🌐

ブラウザ版（PWA）

インストール不要。開いている間だけ動作します。ホーム画面に追加するとアプリのように使えます。

yggchat.surge.sh

Termux用 android-arm64 ／ SHA256SUMS ／ すべてのリリース

ベータ版です。更新が多く、互換性のない変更もしばらく頻繁に入ります。できるだけ最新版を使い、相手にも更新してもらってください。

ソースからビルド

Go（go.mod のバージョン）が必要です。Twemojiの画像はリポジトリに含めていないので、最初に取得します。

./twemoji/fetch.sh                      # twemoji/svg.zip を作成
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -checklinkname=0" .
GOOS=js GOARCH=wasm go build -trimpath -ldflags="-s -w" -o pwa/ygg.wasm ./wasm

Android APK（Gradle不使用）: libyggchat.so（GOOS=android GOARCH=arm64 のバイナリ）を android/ に置いて android/build.sh。 ANDROID_HOME、YGG_KEYSTORE、YGG_KS_PASS で SDK と署名鍵を指定できます。GitHub Actions（.github/workflows/build.yml）が push ごとにAPKと各バイナリを作り、v* タグでReleaseに載せます。署名鍵は android/yggchat.jks.enc（AES-256で暗号化）で、復号キーはリポジトリのSecret KEYSTORE_KEY にだけあります。Secretがない場合のAPKは使い捨て鍵で署名され、インストール済みのYggChatを上書きできません。PWA（yggchat.surge.sh）の公開はActionsとは別に行っています。
